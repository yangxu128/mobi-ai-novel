# 墨笔 AI 提示词模板库（内部参考）

> 本文是 `src/lib/ai/prompts.ts` 的配套说明文档，按当前实现整理。
> 提示词的**唯一事实来源是源码**，本文用于快速理解各提示词的设计意图与结构，修改提示词时请同步更新本文。

## 统一结构

所有提示词采用同一骨架：**[系统角色] + [任务指令] + [知识库上下文(RAG)] + [用户指令] + [输出格式]**。

### 共享系统基础（buildSystemBase）

所有 System Prompt 以同一段基础设定开头：

- 专业的中文小说创作助手定位；
- 严格遵守用户的世界观与角色设定，保持长篇一致性；
- 若项目配置了**作家风格档案**（StyleProfile），会在此处注入对应的文风模仿指令（强度可调）。

### 全书规模注入（bookScaleGuide）

项目设定了**目标章节数 / 每章字数**后，大纲类提示词会自动注入规模块：

- 首次生成：要求先在心中铺完全书弧线（中段高潮、结局走向、各卷功能划分），再落第一卷；
- 续写：按当前进度感知阶段（前期/中期/后期）对齐烈度；
- 剩余 ≤ 8 章：自动进入**收官模式**，要求规划结局、兑现主线、回收全部伏笔。

### RAG 分层上下文（buildChapterContext）

| 层级 | 范围 | 处理方式 |
|---|---|---|
| 世界观 | 全量 | 按 category 取所有设定 |
| 角色 | 全量 | 按 role 排序（主角优先） |
| 故事状态卡 | 全局 | 记忆 wiki 提取的角色状态/事件/伏笔 |
| 近期章节 | 最近 3 章 | 原文（截断 3000 字） |
| 中期章节 | 更早 5 章 | 摘要 |
| 当前大纲 | 指定大纲 | 场景标题 + 摘要 + 情节点 |

## 提示词清单

### 1. 灵感卡生成 — `inspirePrompt`

- **触发**：流水线第 1 步，一句话点子生成 3 张灵感卡
- **要点**：核心点子中的核心奇设必须原样保留并强化，不得替换弱化
- **输出**：JSON 数组 ×3（core / conflict / audience / mood / reference）

### 2. 世界观构建 — `worldbuildPrompt`

- **触发**：流水线第 2 步，灵感 → 完整世界观
- **要点**：结构化、可扩展、自洽
- **输出**：JSON 对象（background / geography / rules / system / conflict）

### 3. 角色卡生成 — `characterPrompt`

- **触发**：流水线第 3 步，世界观 → 主角 + 核心配角
- **要点**：每个角色要有内在矛盾与成长弧光；配角有自己的立场与利益，禁止工具人；性格字段必须含说话方式（可盲认台词）
- **输出**：JSON 数组 ×4-5（name / role 枚举 / appearance / personality / background / motivation / arc）

### 4. 大纲生成 — `outlinePrompt`

- **触发**：流水线第 4 步，生成第一卷大纲（8-12 章）
- **核心设计**（按题材自动二选一）：
  - **番茄节奏蓝图**：每 3 章"压-小扬-压-爆"情绪循环；主角"压→反击→代价"
  - **关系推进蓝图**（情感向/含核心奇设）：每 3 章"事件-涟漪-升温"关系循环
- **通用骨架**：主线先行（先拟主线句）、起承转合、阶段高潮公式（目标→阻碍→代价→收获→新问题）、黄金节奏点、设定事件化
- **注入**：全书规模（bookScaleGuide）
- **输出**：JSON 数组（volume / chapter / sceneTitle / sceneSummary / povCharacter / plotPoints / foreshadowing）

### 5. 大纲续写 — `outlineAppendPrompt`

- **触发**：第 4 步"继续生成"
- **要点**：直接承接最后一章（禁止重新开场）；优先回收已有伏笔；结尾钩子类型不与上一章重复；注入全书规模与进度感知（收官模式自动触发）
- **输出**：同大纲生成，chapter 从 lastChapter+1 连续递增

### 6. 章节扩写 — `expandPrompt`

- **触发**：流水线第 5 步 / 工作台，按大纲扩写正文
- **篇幅**：项目设定每章字数则按其 ±15% 执行，否则默认 2200-2800 字
- **核心设计**：
  - **番茄四段式结构**：开头钩子（前 20%）→ 发展推进 → 高潮时刻 → 结尾钩子（5-10%）
  - **结尾钩子 10 类型**（与上一章不同类型），禁虚假悬念/机械降神/低风险钩子
  - **情绪曲线**：单章至少 3 次情绪变化
  - **去 AI 味强化**：开篇禁环境描写、对话标签密度 ≤30%、动作短句、禁用 AI 高频词、禁"不是A而是B"三毒、禁数字伪精确
  - **人味细则**：语言具体化、生理代偿写情绪、修辞克制、细节三问筛选、叙事手法多样、对话辨识度测试、角色不降智、爽点余波
  - **题材节奏适配**：检测到情感向/奇设故事时切换关系推进模式（优先级最高）
- **上下文**：RAG 分层注入（世界观/角色/前文/大纲/故事状态卡）
- **输出**：纯文本正文（无标题、无前言）

### 7. 润色 — `polishPrompt`

- **方向**：文笔提升 / 对话优化 / 节奏调整 / 环境描写
- **核心设计**：三遍处理——① 去泛化（禁用词→具体动作）② 去书面化（"不是而是"三毒、连接词精简）③ 回自然感（节奏打碎、对话去腔调、结尾去升华）+ 输出前自检清单
- **输出**：润色后的完整文本

### 8. 行内 AI — `inlineAIPrompt`

- **触发**：工作台选中文字 Cmd/Ctrl+K
- **6 个 action**：续写（200-400 字）/ 扩写（400-600 字）/ 润色 / 改写 / 压缩（约一半）/ 古文风格
- **输出**：纯文本

### 9. 对话共创 — `chatCoCreatePrompt`

- **两阶段**：
  - **开场**（storySoFar 为空）：创作引导助手，1-2 句问候 + 3-4 个"我想写：xxx"方向选项
  - **叙事**：富有创意的说书人，200-400 字接龙 + 关键情节点的 2-3 个互斥走向选项（【选项】A/B/C，前端解析为按钮）
- **规则**：遵守已建立的世界观与角色；适度意外转折；可扮演角色对话

### 10. 一致性检查 — `consistencyCheckPrompt`

- **触发**：工作台对章节正文扫描设定矛盾
- **输出**：JSON 数组（quote 原文引用 / conflict 矛盾说明 / suggestion 修改建议），无矛盾输出 `[]`

### 11. 对话提取知识卡 — `extractCardsPrompt`

- **触发**：对话共创"提取知识卡"按钮
- **输出**：JSON（worldSettings + characters 两个数组），分类与角色定位均为受控枚举

### 12. 章节摘要 — `summaryPrompt`

- **触发**：章节保存时自动生成
- **输出**：200 字以内摘要（主要事件 / 角色动作 / 关键转折），用于后续上下文检索

### 13. 风格分析 — `analyzeStylePrompt`

- **触发**：自定义作家风格时，粘贴文本样本让 AI 分析笔风
- **输出**：结构化 StyleProfile（写入项目，生成时注入系统提示）

### 14. 记忆提取 — `wikiExtractPrompt`

- **触发**：章节保存后自动运行（长期记忆系统核心）
- **一次调用合并提取**：摘要 / 事件 / 角色状态增量 / 伏笔增减
- **工程要点**：inflight 防重 + 字数阈值节流（防自动保存风暴）；重提幂等（硬删重建）；旧章重提只追加关系变化不回退角色状态
- **消费方**：扩写与一致性检查时经 `getStoryState` 注入"故事状态卡"
